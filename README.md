# 🪡 Vértice — Atelier de Co-creación

> **Real, personalizado, tuyo.**

Landing page oficial de **Vértice**, un Atelier Moderno de Co-creación que diseña prendas personalizadas adaptadas a la identidad y cuerpo real de cada persona.

## ✨ Características

- 🎨 Diseño visual con paleta pastel (rosados y cálidos)
- 📱 Totalmente responsive (mobile-first)
- ⚡ Sitio estático ultra-rápido
- 🎬 Animaciones suaves con Intersection Observer
- 💬 Integración directa con WhatsApp
- 🔍 SEO optimizado

## 🚀 Deploy

### Vercel
1. Conecta este repositorio a [Vercel](https://vercel.com)
2. El deploy es automático — no requiere configuración adicional

### GitHub Pages
1. Ve a **Settings** → **Pages**
2. Selecciona la rama `main` y la carpeta `/ (root)`
3. Tu sitio estará disponible en `https://tu-usuario.github.io/vertice-web`

## 🛠️ Tecnologías

- HTML5 semántico
- CSS3 (Custom Properties, Grid, Flexbox, animaciones)
- JavaScript vanilla (ES6+)
- Google Fonts (Cormorant Garamond + DM Sans)

## 💕 Marca

**Vértice** simboliza el punto de encuentro exacto entre el deseo del cliente y la ejecución de la marca. Operamos bajo un sistema de **Personalización Absoluta** donde el cliente toma las decisiones de diseño y Vértice acompaña paso a paso.
